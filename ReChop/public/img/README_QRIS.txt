Place your QRIS image here as `qris.png`.

1. Save the QR image file named `qris.png` into this folder:
   ReChop/public/img/qris.png

2. The checkout page will automatically display it when the user selects the "QRIS" payment method.

3. Alternatively, you can provide an absolute URL and change the image `src` in `ReChout/src/pages/utama/Chekcout.jsx` to that URL.

Note: If the image does not appear, run the dev server (`npm run dev`) or rebuild (`npm run build`) to ensure the asset is served.
